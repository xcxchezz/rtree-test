# Демонстрация работы R-дерева

## Описание проекта

Этот проект демонстрирует работу с R-деревом - структурой данных для эффективного пространственного поиска.

## Структура классов

### Оригинальные классы (из rtree-lib-1.0-SNAPSHOT.jar)
- `RTree<T>` - основной класс R-дерева с методами `insert()` и `search()`
- `Rectangle` - представляет пространственный прямоугольник
- `Entry<T>` - запись, содержащая MBR (Minimum Bounding Rectangle) и данные
- `Node<T>` - узел дерева

### Упрощенная реализация (для совместимости с Java 8)
Поскольку оригинальная библиотека скомпилирована для Java 17, а демонстрационная среда использует Java 8, была создана упрощенная реализация:

- `SimpleRTree<T>` - упрощенная версия R-дерева
- `SimpleRectangle` - прямоугольник с методами пересечения и комбинирования
- `SimpleEntry<T>` - запись с прямоугольником и данными
- `SimpleNode<T>` - узел дерева

## Основные возможности R-дерева

1. **Вставка данных**: Каждый объект ассоциируется с пространственным прямоугольником (MBR)
2. **Пространственный поиск**: Поиск всех объектов, пересекающихся с заданным прямоугольником
3. **Автоматическое расщепление узлов**: При превышении максимального количества элементов в узле происходит расщепление

## Запуск демонстрации

```bash
# Компиляция
javac -cp "." -source 1.8 -target 1.8 -encoding UTF-8 src/main/java/rtree/*.java -d target/classes

# Запуск
java -cp target/classes rtree.MainDemo
```

## Пример работы

Программа демонстрирует:
- Вставку 8 объектов (квартиры, офисы, магазины, рестораны) с различными координатами
- Автоматическое построение дерева с расщеплением узлов
- Поиск объектов в различных областях

## Принцип работы R-дерева

R-дерево - это сбалансированное дерево поиска для многомерных данных. Каждый узел содержит:
- MBR (Minimum Bounding Rectangle) - минимальный прямоугольник, охватывающий все дочерние элементы
- Ссылки на дочерние узлы или данные

При поиске алгоритм проходит по дереву, проверяя пересечение MBR узлов с поисковым прямоугольником, что позволяет эффективно отсеивать неподходящие ветви.
